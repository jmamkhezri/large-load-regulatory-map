# State large-load (data center) regulatory action map, 2024-2026

An interactive map of the large-load (data center) electricity-regulation status of all fifty U.S. states, compiled from primary sources as of November 18, 2026. Click any state for its provisions and a primary-source link.

**Interactive map:** https://jmamkhezri.github.io/large-load-regulatory-map/
